# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/0bAndyWirus/r36llm/security/advisories/new). Include the affected version, impact, and steps to reproduce. Do not open a public issue for an undisclosed vulnerability.

Reports concerning the image, OS, and application are in scope. This project does not offer a bug bounty.

## Known risks

The default root password is `r36llm`, and SSH is exposed on the USB-Ethernet link. Change the password before connecting to an untrusted network. These documented defaults are known risks; please report other vulnerabilities privately.
